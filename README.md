# Constraint-Driven Architecture

An open-source Agent Skill for designing and evaluating distributed systems from first principles.

Instead of starting with a stack, protocol, framework, or vendor, this skill starts with:

**Goal → Environment → Desired Properties → Constraints → Interface → State → Failure → Evolution**

It is inspired by Roy Fielding's REST dissertation, Christopher Alexander's pattern-oriented architectural thinking, and the emerging problem of coordinating autonomous AI agents.

## What it helps with

Use it to reason about APIs, distributed applications, agent-to-agent systems, platforms, marketplaces, service boundaries, protocol design, state/resource modeling, caching, intermediaries, interoperability, and independent evolution.

The point is not to make every system RESTful.

The point is to ask:

> What constraints on interaction will induce the properties this system actually needs?

## Skill format

The repository is anchored by `SKILL.md`, following the open Agent Skills convention.
